# ADR-002: カラム依存グラフに petgraph を使う

- 日付: 2026-06-24
- ステータス: 承認済み

## 背景

カラムレベルのリネージュは「このカラムはどのカラムから派生したか」という
有向グラフで表現される。循環依存の検出や到達可能性の計算も必要。

## 決定

`petgraph` の `DiGraph<Column, ()>` でリネージュグラフを構築する。

## 理由

- `is_cyclic_directed()` で循環依存を即座に検出できる
- `Bfs` / `Dfs` で影響範囲の算出が容易
- DeltaForge (R2) でも同じクレートを使っており知見が流用できる

## トレードオフ

- グラフが大規模になると `petgraph` のメモリ効率が課題になる可能性がある
  → MVP 規模（数百テーブル）では問題なし
- シリアライズは手動で JSON に変換する必要がある
